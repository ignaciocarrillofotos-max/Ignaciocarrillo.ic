# Ignacio Carrillo — Web final / GitHub Pages + IONOS

## Estructura limpia
- `index.html` y `galeria.html` en la raíz.
- `assets/`: solo CSS/JS comunes de la versión actual.
- `GALERIA/`: páginas y scripts de las galerías.
- `FOTOSVIDEOS/`: fotografías, vídeos y logotipos originales.
- `musica/`: archivo de audio original conservado.
- `CNAME`: dominio `ignaciocarrillo.es`.

Se han retirado únicamente archivos antiguos de CSS/JS y documentación que ya no utiliza ninguna página. No se ha eliminado ninguna fotografía, vídeo, audio ni logotipo.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## IONOS
El dominio debe apuntar a GitHub Pages y GitHub Pages debe tener configurado el dominio personalizado `ignaciocarrillo.es`.
