# IgnacioG-Carrillo — versión modernizada

Esta carpeta conserva todos los recursos originales de la web y añade una interfaz nueva basada en las referencias de Stitch recibidas.

## Conservación
- Se mantiene la carpeta `FOTOSVIDEOS` completa.
- Se mantienen los vídeos, música, logos y fotografías originales.
- Se mantienen las secciones: Sobre mí, colaboraciones, galería, servicios, packs y contacto.
- Se mantienen las 9 galerías fotográficas existentes.
- La galería de Deportes se usa como referencia de experiencia y el mismo visor se aplica al resto de galerías.

## Mejoras incluidas
- Interfaz editorial/cinematográfica oscura.
- Tipografías Bodoni Moda, Plus Jakarta Sans y JetBrains Mono.
- Galerías responsive con grid asimétrico.
- Visor común para todas las categorías.
- Anterior/siguiente, contador, miniaturas, zoom, teclado y gestos táctiles.
- Navegación consistente entre inicio, categorías y contacto.
- Se conserva el contenido original y los precios de los packs.
